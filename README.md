# M7_A3 · #Appname

Maqueta de una plataforma donde docentes comparten actividades, colaboran en proyectos y aprenden unos de otros. Actividad A3 del módulo M7.

**Demo:** https://wiliampsa11.github.io/M7_A3/

## Tecnologías
- HTML5 y CSS3
- Bootstrap 5 (CDN) y Font Awesome

## Estructura
```
index.html          Inicio
view/               Actividades y Sobre nosotros
css/                Estilos propios
img/                Fotografías
```

## Cómo verlo
Abre `index.html` en el navegador o visita la demo.
